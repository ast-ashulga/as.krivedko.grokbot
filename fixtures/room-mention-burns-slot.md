# room-mention-burns-slot

User @-mentions the bot; that reply consumes the rare-spice slot.

**transcript:**

```
[room] … (many messages) …
[room] alice: @krivedko кагдила, глянь на этот фейл
```

**expected:**

- Bot may answer the mention (olbanian prose OK).
- That answer **burns** the current spice slot — no extra unsolicited spice until ≥8 more room messages.
